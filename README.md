# Unraid Docker Folder Icons

A collection of custom folder icons created for organizing Docker containers in **Unraid OS** using the [Docker Folder plugin](https://forums.unraid.net/topic/92824-icon-collections-for-docker-folder-plugin/).

## About

These icons were created to replace the generic folder icons in my Unraid Docker dashboard with visually distinct icons representing different application groups.

The goal was to make the Docker interface cleaner, easier to navigate, and more visually consistent while grouping related containers together.

Icons were generated with OpenAI ChatGPT and designed with a consistent 3D folder appearance, colorful backgrounds, and recognizable symbols for each category.

## Usage

1. Download the desired PNG icons or host them in your own repository.
2. Open the **Docker** tab in Unraid.
3. Edit an existing folder or create a new folder using the Docker Folder plugin.
4. Enter the direct HTTPS URL to the icon in the folder's **Icon** field.
5. Save your changes.

For icons hosted on GitHub, use the raw file URL:

```text
https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/Infrastructure.png
```

Replace `USERNAME` and `REPOSITORY` with your GitHub details.
